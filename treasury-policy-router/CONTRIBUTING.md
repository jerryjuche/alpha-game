# Contributing to Treasury Policy Router

## Issue Report Flow

1. Browse open issues.
2. Comment on an issue to express interest.
3. A maintainer assigns the issue.
4. Submit a PR against `main`.

## Commit Convention

```
feat(contract): add check_policy daily cap logic
fix(indexer): handle null event fields on empty pages
docs: add Travel Rule worked example
chore: upgrade soroban-sdk to 27.0.0
```

## PR Rules

- One PR per issue.
- PR description must reference the issue number.
- CI must pass before review.

## Labels

- `enhancement` — new feature
- `bug` — broken behavior
- `documentation` — docs only
- `complexity:100/150/200` — Wave points estimate
