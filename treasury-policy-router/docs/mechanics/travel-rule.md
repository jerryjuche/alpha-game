# Travel Rule

The Travel Rule requires financial institutions to include originator and beneficiary information on wire transfers above a threshold.

Treasury Policy Router does not make Travel Rule determinations. It flags transactions above a configurable threshold for human review.

## Threshold math

| Field | Value |
|-------|-------|
| Threshold | 100_000_000 stroops |
| Example amount | 150_000_000 stroops |
| Flag | true |
