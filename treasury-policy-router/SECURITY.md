# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Email `security@yourname.com` with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Suggested fix (if any)

## Scope

- `policy-hook` Soroban contract
- `packages/sdk`, `packages/indexer`, `packages/api`, `apps/web`

## Audit Status

This project is unaudited. Do not use on mainnet with real funds.
